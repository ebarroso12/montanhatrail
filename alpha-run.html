A coleção

Quatro cores. Um só padrão.

Cada cor do Alpha Run carrega a mesma engenharia — muda o squad, não o desempenho. Toque numa cor para ver o par completo.

Engenharia do produto

Construído para repetir, não para descansar.

Todo detalhe do Alpha Run pensa no dia de treino: entrar, amarrar e ir. Sem ajustes, sem desculpas.

  • 01

    Cabedal em malha respirável

    Tecido flexível que acompanha o movimento do pé e ventila no treino mais intenso.

  • 02

    Entressola macia

    Amortecimento pensado para séries longas, agachamento, corda naval e o deslocamento curto entre estações.

  • 03

    Solado de alta tração

    Desenho de solado antiderrapante para apoio firme em piso de academia, esteira e asfalto.

  • 04

    Modelagem unissex

    Um só padrão de numeração adulto, para todo o squad treinar com o mesmo tênis.
